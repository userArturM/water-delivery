# Чистая вода — сайт доставки

Многостраничный сайт на HTML/CSS/JavaScript с PHP-обработчиком заказа. Цены, ассортимент, телефон и территория доставки сохранены из исходного проекта.

## Обновление 2.2

- Новый светлый сине-белый дизайн главной, каталога, информационных страниц и корзины.
- Адаптивная типографика, карточки товаров, навигация и состояния кнопок.
- Плавные появления и движение изображения на главной; системная настройка уменьшения движения отключает анимации.
- Поиск по названию и описанию, сортировка по цене и названию, сброс пустого результата.
- Выбор станицы непосредственно в корзине с пересчётом цены и минимального заказа.
- Ограничение количества до 99 на позицию, безопасное восстановление повреждённых данных корзины.
- Независимые согласия, проверка даты и способа оплаты, ограничение ожидания отправки 20 сек.
- Ответ HTML со статусом 200 больше не считается отправленной заявкой. Ожидается статус 204 от PHP.
- Закрытая корзина исключена из клавиатурной навигации; Tab удерживается в открытой корзине, Escape закрывает её.
- Убрана заставка, задерживавшая доступ к странице. Добавлены уведомления о потере и восстановлении сети.
- Обновлён кеш приложения; очистка затрагивает только кеши с префиксом `clean-water-`.

## Запуск

Для просмотра интерфейса:

```sh
python3 -m http.server 8000
```

Открыть http://localhost:8000. Это статический просмотр: Python и GitHub Pages не исполняют PHP и не отправляют заявки.

Для работы заказов нужен хостинг с PHP 8+ и настроенной отправкой `mail()`. Положите HTML, CSS, JS, PHP и папку `assets` в одну директорию. Сборка frontend не требуется. Получатель задан в `send-order.php`. Перед выпуском на рабочий домен проверьте доставку тестового письма в почтовый ящик: успешный `mail()` означает принятие письма почтовой системой, а не гарантию доставки.

## Проверки

Node.js 20+ и Python 3:

```sh
npm ci
npx playwright install --with-deps chromium
npm run check
npm test
```

Если Chromium установлен отдельно, можно передать `CHROMIUM_PATH=/путь/к/chromium`. Тест сам запускает локальный HTTP-сервер на порту 8765. Все запросы отправки заказов перехватываются: письма не отправляются.

Проверены поиск, сортировка, расчёт корзины, минимальное количество для разных станиц, независимые согласия, прошедшая дата, неуспешная/успешная отправка, повтор заказа и повреждённое локальное состояние. Семь страниц проверяются на горизонтальное переполнение при ширинах 320, 390, 768 и 1440 px. Контролируются ошибки JavaScript.

Главная и каталог дополнительно просмотрены в Chromium на десктопе и мобильном размере. Внешние шрифты, карты и аналитика отключены в автоматических проверках. Проверка реальной отправки почты, Safari/iOS и рабочего хостинга остаётся отдельным этапом выпуска.

## Изменение каталога

Данные товаров и правила доставки находятся в `app.js`: `waters`, `TOWNS`, `TOWN_SURCHARGE`, `TOWN_MIN_BOTTLES`. Базовая раскладка — `styles.css`, актуальная визуальная система — `premium.css`. При изменении файлов обновляйте версию `CACHE` в `sw.js`, чтобы установленное приложение получило свежие ресурсы.

Не храните секреты в клиентском JavaScript. Сайт не содержит базы заказов, онлайн-эквайринга или административной панели; сервер получает заявку для подтверждения оператором.
